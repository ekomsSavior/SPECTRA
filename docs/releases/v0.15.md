# SPECTRA v0.15 — Portable evidence and resumable lessons

Debugger observations can now travel with an investigation. Notebook users can select evidence categories and review a checksum inventory before downloading. File structure translates offsets/RVAs/VAs using actual declared, captured or raw mappings. Training ground preserves versioned evidence milestones for five benign workflows across reloads and portable projects.

- Portable trace import is inert. Two slots support search, recorded change inspection, same-sample navigation and retained-order comparison. Latest 200 instruction records, bounded model events and final mappings are labeled honestly; complete recording and reverse stepping remain future work.
- Bundle exports default to findings only. Original, recovered, dependency, comparison, analysis, experiment, trace and lesson data have separate controls. Inventory hashes are checked before explicit restoration; unknown schema versions are inspection only.
- Mapping preserves exact unsigned 64-bit arithmetic and identifies zero-fill, allocated pages, file-only data and ambiguous regions. Captured relocations/bias and extracted-child provenance stay explicit.
- Lesson checks bind to exact fixture hash/version and actual observed evidence. Historical imported checks are labeled. Exercise replacement asks before discarding the active sample; resume never silently executes a sample.

See [workflow/schema reference](../EVIDENCE-WORKFLOWS.md) for bounds and privacy implications. Existing project and replay formats remain compatible. No new OS shell, required companion, account, sample upload or paywall is introduced. The new beginner/intermediate manuals remain unpublished. Existing in-app reference chapters explain the new controls.

Verification: 19 new model/security tests plus the existing regression suite; actual Windows/Linux/ARM benign emulator traces; malformed/truncated/checksum/oversize inputs, privacy exclusions, bundle members, high addresses, BSS, rebases and ARM PIE mapping; browser capture/import/compare, mapping navigation, selected inventory, explicit restore and full-reload lesson resume. Detailed release verification records tested scope, actual counts, browser checks and publication identifiers. Narrow-viewport desktop checks are not physical iPad/phone performance validation.
