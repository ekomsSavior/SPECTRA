# SPECTRA v0.12 — integrated debugger environments

Opening a binary now selects the detected CPU and process model. Preflight uses the actual loader validation and shows incompatible setup, missing ELF interpreter/shared-library requirements, unsupported TLS/PIE and Windows import/API coverage before initialization. Missing imports remain visible while allowing inspection; execution stops if an unmodeled API is reached.

Static little-endian Linux ET_EXEC support adds x86, ARM EABI5 and Thumb to x64/AArch64. The loader preserves mapped segments and zeroed BSS, builds pointer-width-correct process stacks, and selects ARM user/Thumb state. Syscall handling includes bounded virtual vector I/O and additional process identity/path queries. This is an explicit userspace model, not a full OS or general libc implementation.

All profiles share live memory maps, stepping, breakpoints, watchpoints and verified checkpoint replay. Modeled writes now record before/after bytes, including partial-fault evidence. Thumb state survives manual/modeled program-counter writes. Local data files can be attached to virtual paths through a file picker.

The standalone System lab navigation, UI, shipped worker and Training ground chapter were removed. Its research code remains unshipped. The DiE runtime is retained for detection. Existing #system links resolve to Debugger lab.

Validation: real Unicorn execution on five benign Linux fixtures; ABI stacks, watchpoints, output, signed syscall arguments, vector I/O, negative loader cases, missing Windows imports, partial-write traces and verified replay. Full existing regression suite and browser checks also run. A 390-pixel desktop viewport is a layout check, not proof of iOS/Safari support.
