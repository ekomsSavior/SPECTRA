PUPPET CORE / SPECTRA SETUP
CTF 008 builds on 004's indirect calls/state and 007's coordinate discipline.
This is a custom accumulator bytecode machine, NOT a real malware sample,
a PE file, Java/.NET, or a VM that runs an operating system.
Do not run any supplied file natively. All routines are inert arithmetic.

NATIVE CODE: Open interpreter.bin > Disassembly > Raw range / architecture
override. File offset 0x0, byte length 0x326 (806 decimal / 0x326 hex),
base VA 0xc000, x86-64, Little endian. Click Decode range; choose All decoded
instructions. CC bytes are padding, not useful instructions. The table at
file offset 0x400 is DATA: inspect it in Hex explorer, not as x86 code.
For less clutter decode each row separately. Set ALL fields each time.

STATE REGISTER LEDGER (exercise scaffolding, confirm writes in code):
RDI = pointer to selected bytecode, RSI = bytecode length
R10D = virtual PC; R11B = accumulator A; R12B = counter N
R13B = stored virtual zero condition Z; R8D = dispatched instruction count
R14D = remaining 64-instruction budget. RBX anchors the handler table.
Native CPU flags are temporary; they are NOT the saved virtual Z value.

INPUT CONTRACT: RCX=readable bytecode pointer, EDX=length (0..4096),
R8B=one caller input byte, R9B=initial counter from container header.
The harness selects the window and checks the container; interpreter.bin
itself does not parse PPC8 headers. Program entry is virtual PC 0.
OUTPUT: EAX=status; EDX=final accumulator only if status=0, otherwise zero.
Status 0=HALT, 1=invalid opcode, 2=missing opcode/operand,
3=taken branch outside selected window, 4=64-instruction budget exhausted.
A HALT result 1 is acceptance for THIS program; HALT result 0 is rejection.
A failed run is neither. RBX,RSI,RDI,R12,R13,R14 and stack are preserved.

ADDRESS SPACES: native VA = 0xc000 + interpreter.bin file offset.
Virtual PC is an index into a DIFFERENT selected bytecode window.
Container file offset = bytecode_start + virtual PC.
Captured bytecode memory address = 0x10000 + virtual PC.
Do not add the container header twice, or confuse native RIP and virtual PC.
