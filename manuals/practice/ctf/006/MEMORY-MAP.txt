WINDOWS X64 INTEGER ARGUMENTS (review): RCX, RDX, R8, R9; result EAX here.
name_hash: RCX points to a readable NUL-terminated byte string. Returns zero-
extended u16 in EAX; seed is zero. Caller guarantees a readable terminator.
No bound is implemented in this deliberately small teaching routine. Analyze
only supplied terminated strings; the browser worksheet is separately bounded.
resolve: RCX=first table row; EDX=row count; R8W=request hash; R9B=name length.
Returns first matching target VA in EAX, or 0. Caller validates table storage.
It compares metadata, not strings; hash+length is not a universal unique ID.
dispatch: RCX points to a readable 16-byte config. RDX=validated callback VA.
No NULL callback check exists: the harness calls only after a nonzero lookup.
QueueNote stub: ECX=status input; copies ECX to EAX. It does NOTHING else.
dispatch allocates shadow space/alignment for its indirect call. The routines
do not have a PE unwind directory and are not a complete Windows executable.
